NanoGS가 받는 PLY spec (참고)

source 분석(PLYFileReader.cpp) 결과:

  • 표준 INRIA Gaussian Splatting PLY 준수.
  • 필수 properties: x, y, z, opacity, scale_0, scale_1, scale_2, rot_0, rot_1, rot_2, rot_3, f_dc_0, f_dc_1, f_dc_2.
  • 선택: f_rest_0 ... f_rest_44 (SH bands 자동 감지, 1/2/3 bands 모두 지원).
  • 속성 이름 기반 조회: PLY property 순서 자유. PlayCanvas 변형 PLY도 받음.
  • normal(nx, ny, nz), RGB uchar 불필요.
  • 좌표계: COLMAP/OpenCV(Y-down) 가정 → UE(Z-up) 자동 변환 + 100x scale (meters → cm) 자동 적용.
